# Talking John Mobile

Мобильная оболочка для приложенной игры Talking John с записью и воспроизведением изменённого голоса, а также локальным аудиотреком.

## Запуск

Открой `index.html` через локальный сервер или загрузи содержимое папки в GitHub Pages. Для доступа к микрофону необходим HTTPS (GitHub Pages его предоставляет автоматически). Игра находится в `game.html`, музыка — `kogda-ya-vyrastu.aac`.

На телефоне лучше открыть сайт в альбомной ориентации. Встроенная игра — оригинальный TurboWarp-пакет из предоставленного файла. Эффект голоса использует микрофон устройства и Web Audio API; запись остаётся на устройстве.

## Публикация через GitHub

1. Создай новый пустой публичный репозиторий.
2. Загрузи все три файла (`index.html`, `game.html`, `kogda-ya-vyrastu.aac`) в корень.
3. В Settings → Pages выбери Deploy from a branch, ветку `main`, папку `/ (root)`.
4. Открой адрес Pages после завершения публикации.

Не удаляй и не переименовывай соседние файлы: HTML использует `game.html`, а проигрыватель — AAC-трек.
